# ML & Exploratory Statistics Learning 📚

A comprehensive learning project focusing on Machine Learning fundamentals combined with Exploratory Statistics techniques.

## 📊 Project Overview
This repository documents learning and practice with Machine Learning algorithms integrated with statistical analysis and exploratory methods.

## 🛠️ Technologies Used
- **Python 3**
- **NumPy** - Numerical computations
- **Pandas** - Data analysis
- **Matplotlib & Seaborn** - Visualization
- **Scikit-learn** - ML algorithms
- **SciPy** - Statistical functions
- **Jupyter Notebook** - Interactive environment
